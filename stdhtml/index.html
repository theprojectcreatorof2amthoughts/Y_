Y_ library reference

stdhtml

Small Y_ helpers for assembling HTML strings. Import a module into a script, compose elements, then redirect Y_ output to an .html file.

!#inclib %stdhtml/document.yl%

Library index

elements.yl

Common paired tags and a couple of void tags. Content is inserted as provided.

!#inclib %stdhtml/elements.yl%
html_h1(content) · html_h2(content) · html_p(content) html_div(content) · html_section(content) · html_main(content) 
stash heading = html_h1("Y_ page")
stash copy = html_p("Built from Y_ strings.")
writescrn >^ heading + copy

attributes.yl

Helpers for a few tags that carry attributes.

!#inclib %stdhtml/attributes.yl%
html_link(content, url) html_image(source, alt_text) · html_button(content, type) html_css_link(path) · html_script_link(path) 
stash home = html_link("Home", "/")
writescrn >^ home

document.yl

Page wrapper with a doctype, UTF-8 metadata, viewport metadata, title, and body tags. Imports elements.yl for page helpers.

!#inclib %stdhtml/document.yl%
html_page(title, body) html_page_start(title) · html_page_end 
stash body = html_main(html_h1("Hello"))
writescrn >^ html_page("My page", body)
Y_ currently has no HTML escaping helper. These functions insert strings as raw markup; only pass trusted content, or escape user-provided text before using it in a page.
The libraries are embedded during the build. Generate a page with ./y_ stdhtml/demo.yc > page.html, then open page.html in a browser.
